## 🚀 1-Minute Deployment on GitHub Pages

1. 在 GitHub 建立一個全新的公開倉庫（例如命名為 `bse-l01-heating`）。
2. 將本專案的 4 個檔案放置於倉庫根目錄：
   - `index.html`
   - `style.css`
   - `app.js`
   - `README.md`
3. 提交並推送到 GitHub：
   ```bash
   git add .
   git commit -m "Deploy BSE Lecture 1 Space Heating interactive platform"
   git branch -M main
   git push -u origin main
